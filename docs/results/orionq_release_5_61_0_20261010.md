## Reproduzir

Em uma instalação limpa, com as dependências e recursos descritos nas [notas da versão](../product/orionq_release_5_61_0.md):

```powershell
powershell -ExecutionPolicy Bypass -File tools\build_windows_console.ps1 -SkipInstaller
```

Esse comando cria uma nova pasta de release e repete os gates oficiais. O script de retomada preservado é evidência desta interrupção; não é o procedimento de build de um checkout limpo.

Para conferir os bytes antes da execução, use o verificador da instalação fonte:

```powershell
python tools\verify_frozen_source.py --exe <pasta-release>\OrionQ\OrionQ.exe --output outputs\nova-comparacao.json
python tools\consolidate_native_release.py --release-root <pasta-release> --frozen-source-report outputs\nova-comparacao.json --output outputs\nova-consolidacao.json
```

Use arquivos novos; os verificadores recusam sobrescrever evidências. Compare os relatórios com este escopo e mantenha a pasta portátil inteira ao lado do EXE.
